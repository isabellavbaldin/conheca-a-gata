# Conheça a Gata 🐈

Trata-se do meu primeiro projeto de página web, desenvolvido para praticar HTML e CSS. Feito em 24/08/2026.

## Sobre o projeto

Uma página de apresentação da minha gata de 9 anos, com fotos, curiosidades e informações sobre sua personalidade.

## Tecnologias utilizadas

- HTML5
- CSS3

## O que aprendi

- Estruturação de páginas com HTML
- Estilização com CSS
- Inserção de imagens e links
- Utilização de classes CSS
- Organização do código em arquivos separados
- Desenvolvimento utilizando o Visual Studio Code
